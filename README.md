# Лабораторные работы по сетевым технологиям

Курс: **Сетевые технологии**.  
НИТУ МИСИС, 4 семестр.

В репозитории собраны цифровые версии лабораторных работ. Формат: схема, ход выполнения, команды, проверки, наблюдения и выводы по ходу работы.

## Состав лабораторных

| № | Тема |
|---|---|
| 1 | Базовая настройка коммутатора, VLAN управления, Telnet и SSH |
| 2 | Работа коммутатора, MAC-таблица, ARP-таблица и ICMP-проверки |
| 3 | VLAN, DTP, trunk/access-порты и VTP |
| 4 | Статическая маршрутизация, ping, tracert и проверка резервного пути |
| 5 | STP и межвлановая маршрутизация Router-on-a-Stick |
| 6 | RIP, OSPF, loopback-интерфейсы и redistribution |
| 7 | DHCP и EIGRP |

`.pkt` файлы Packet Tracer лежат рядом с README соответствующей лабораторной, если они сохранились.
